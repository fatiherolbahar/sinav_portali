# Üniversite Sınav Simülatörü

Sıfır backend, GitHub Pages uyumlu çoklu ders sınav portalı.

```
index.html / exam.html   sayfalar
css/ js/                 stil ve mantık
data/                    courses-manifest.js + ders dosyaları
assets/                  logo.svg, ikonlar, og-image.png
legacy/                  eski tek dosyalı sürüm (arşiv)
```

Yeni ders: data/ altına dosya ekle (window.COURSE_DATA[id]) ve courses-manifest.js içine kayıt ekle.
